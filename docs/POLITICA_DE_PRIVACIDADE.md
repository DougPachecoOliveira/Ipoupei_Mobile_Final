## 3. COMO USAMOS SEUS DADOS

Utilizamos suas informações para:

- **Fornecer o serviço:** Permitir o controle de suas finanças pessoais
- **Sincronização:** Manter seus dados sincronizados entre dispositivos
- **Suporte:** Responder suas dúvidas e solicitações
- **Melhorias:** Aprimorar a experiência do usuário
- **Comunicação:** Enviar notificações importantes sobre o serviço
- **Segurança:** Proteger contra uso fraudulento ou não autorizado

**Não utilizamos seus dados para:**
- Vender para terceiros
- Publicidade direcionada
- Análise de crédito
- Compartilhar com instituições financeiras

## 4. ARMAZENAMENTO E SEGURANÇA

### 4.1 Onde seus dados são armazenados

| Local | Tipo de Dados | Segurança |
|-------|---------------|-----------|
| **Dispositivo local** | Dados financeiros (SQLite) | Criptografia do dispositivo |
| **Nuvem (Supabase)** | Dados de sincronização | Criptografia em trânsito e repouso |
| **Servidores seguros** | Dados de autenticação | Protocolos OAuth 2.0 |

### 4.2 Medidas de segurança

- Criptografia de dados em trânsito (HTTPS/TLS)
- Criptografia de dados em repouso
- Autenticação segura via OAuth 2.0 (Google)
- Backups regulares e seguros
- Acesso restrito aos dados por funcionários autorizados
- Monitoramento de segurança contínuo

### 4.3 Retenção de dados

Mantemos seus dados enquanto sua conta estiver ativa. Após solicitação de exclusão:
- Dados pessoais: excluídos em até **30 dias**
- Backups: excluídos em até **90 dias**
- Logs anonimizados: podem ser mantidos para análise estatística

## 5. COMPARTILHAMENTO DE DADOS

### 5.1 Com quem compartilhamos

| Parceiro | Finalidade | Dados Compartilhados |
|----------|------------|---------------------|
| **Google** | Autenticação (login) | E-mail, nome |
| **Supabase** | Infraestrutura de nuvem | Dados sincronizados (criptografados) |

### 5.2 Não compartilhamos

- **Nunca vendemos** seus dados pessoais
- **Nunca compartilhamos** com anunciantes
- **Nunca compartilhamos** com instituições financeiras
- **Nunca compartilhamos** para fins de análise de crédito

### 5.3 Exceções legais

Podemos divulgar dados quando exigido por:
- Ordem judicial
- Requisição de autoridades competentes
- Proteção de direitos da ASTRACORTEX
- Situações de emergência envolvendo segurança
