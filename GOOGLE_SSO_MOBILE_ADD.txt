📋 PASSO 1: ADICIONAR ANDROID NO GOOGLE CLOUD CONSOLE
═══════════════════════════════════════════════════════════════════

1. Acesse: https://console.cloud.google.com/apis/credentials

2. Selecione o projeto "iPoupei" (mesmo do React)

3. Na lista de "OAuth 2.0 Client IDs" você já deve ver:
   - iPoupei Web (ou similar) ← Esse é do React

4. Clique em: + CREATE CREDENTIALS → OAuth client ID

5. IMPORTANTE: Não precisa refazer o OAuth consent screen!

6. Criar NOVO Client ID para Android:
   ════════════════════════════════════════════════════════════

   Application type: Android

   Name: iPoupei Mobile Android

   Package name: com.example.ipoupei_mobile

   SHA-1 certificate fingerprint:
   B1:AD:28:BA:31:59:F0:25:02:40:AC:18:7C:81:78:38:82:A9:01:E8

   Clique em CREATE

7. Você receberá um novo Client ID para Android
   (Não precisa do Client Secret no Android)

═══════════════════════════════════════════════════════════════════
📋 PASSO 2: ADICIONAR O CLIENT ID ANDROID NO SUPABASE
═══════════════════════════════════════════════════════════════════

1. Acesse: https://supabase.com/dashboard

2. Projeto iPoupei → Authentication → Providers

3. Clique em "Google" (já deve estar habilitado)

4. No campo "Authorized Client IDs", você já deve ter o Client ID Web

5. ADICIONE o novo Client ID Android:
   ════════════════════════════════════════════════════════════

   Separe com vírgula ou espaço (Supabase aceita múltiplos):

   ANTES (só Web):
   123456-web.apps.googleusercontent.com

   DEPOIS (Web + Android):
   123456-web.apps.googleusercontent.com,987654-android.apps.googleusercontent.com

6. Clique em SAVE

⚠️ NÃO precisa mexer na Callback URL - ela é a mesma!

═══════════════════════════════════════════════════════════════════
🎯 DIFERENÇA WEB vs MOBILE
═══════════════════════════════════════════════════════════════════

WEB (React):
- Usa OAuth Client ID Web
- Redirect: window.location.origin/dashboard
- Funciona no navegador

MOBILE (Flutter):
- Usa OAuth Client ID Android
- Redirect: ipoupei://login-callback
- Funciona no app nativo

AMBOS usam o MESMO:
- Projeto Google Cloud
- OAuth consent screen
- Supabase provider
- Callback URL do Supabase
