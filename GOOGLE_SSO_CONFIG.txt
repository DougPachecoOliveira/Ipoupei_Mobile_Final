🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

❌ Erro: "redirect_uri_mismatch"
   Solução:
   - Verifique se adicionou a Callback URL no Google Cloud Console
   - URL exata: https://ykifgrblmicoymavcqnu.supabase.co/auth/v1/callback

❌ App não volta após login no Google
   Solução:
   - Verifique se os deep links estão no AndroidManifest.xml
   - Teste manual: adb shell am start -a android.intent.action.VIEW \
     -d "ipoupei://login-callback"

❌ Erro: "invalid_client"
   Solução:
   - Verifique se o SHA-1 está correto no Google Cloud Console
   - Verifique se o Package Name está correto

❌ Botão Google não aparece
   Solução:
   - Certifique-se que está usando LoginIpoupeiPage
   - Verifique se está no modo AuthMode.login
